## Troubleshooting Common Issues

Install issues? Index plain text or simple formats, since complex layouts reduce retrieval quality.  
Performance problems? Reindex after moving files, as stale paths break source excerpts.  
License/activation? Switch to a smaller model when answers take too long on CPU.  
Compatibility? Check that the index folder has read permissions.  
Update failures? Update the app when a document format fails to parse.
